# Data

Raw datasets are not redistributed in this repository.

Place these files in `data/raw/` to run the notebooks:

- `diabetes_binary_5050split_health_indicators_BRFSS2015.csv`
- `Pima Indians Diabetes Database.csv`
- `Shanghai_T2DM_cleaned.xlsx`

The main BRFSS model uses four predictors: `BMI`, `Age`, `HighBP`, and `HighChol`.

The external datasets do not contain perfectly equivalent variables. The evaluation notebook documents the mappings and assumptions used in the original project.
